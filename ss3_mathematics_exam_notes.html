1 Logarithms & Indices

1.1 Laws of Logarithms

If ax = y, then loga y = x (where a > 0, a ≠ 1).

LawFormula
Product Lawloga(M × N) = loga M + loga N
Quotient Lawloga(M ÷ N) = loga M − loga N
Power Lawloga(Mp) = p × loga M
Additional Properties:
loga 1 = 0  |  loga a = 1  |  loga ax = x  |  aloga x = x
Change of Base: loga b = logc b ÷ logc a

1.2 Solving Logarithmic Equations

Worked Example 1

Solve: log3(x+2) + log3(x−4) = 2 + log3(2x−5)

Solution

Step 1: Apply Product Law on LHS

log3[(x+2)(x−4)] = 2 + log3(2x−5)

Step 2: Move log3(2x−5) to LHS

log3[(x+2)(x−4)] − log3(2x−5) = 2

Step 3: Apply Quotient Law

log3[((x+2)(x−4))/(2x−5)] = 2

Step 4: Convert to exponential form

((x+2)(x−4))/(2x−5) = 3² = 9

Step 5: Cross-multiply and solve

(x+2)(x−4) = 9(2x−5)
x² − 2x − 8 = 18x − 45
x² − 20x + 37 = 0
x = [20 ± √(400 − 148)]/2 = [20 ± √252]/2
x = 10 ± 3√7
x ≈ 17.94  or  x ≈ 2.06

Check: x ≈ 2.06 makes (x−4) negative → Reject

Answer: x = 10 + 3√7 ≈ 17.94

1.3 Exponential Growth and Decay

Key Formula: P(t) = P₀ × ekt
Doubling Time Form: P(t) = P₀ × 2t/T   (T = doubling time)
Worked Example 2

Population doubles in 25 years. How long to triple?

Solution

Step 1: Use doubling time formula

P(t) = P₀ × 2t/25

Step 2: For tripling, P(t) = 3P₀

3 = 2t/25
log 3 = (t/25) × log 2
t/25 = log 3 / log 2 = 0.4771 / 0.3010 = 1.5850
t = 25 × 1.5850 ≈ 39.6 years
Answer: Approximately 39.6 years

1.4 Solving Indicinal Equations

Worked Example 3

Solve: 22x+1 − 5(2x) + 2 = 0

Solution

Step 1: Rewrite 22x+1 = 2 × (2x)²

Step 2: Let y = 2x

2y² − 5y + 2 = 0
(2y − 1)(y − 2) = 0
y = 1/2  or  y = 2

Step 3: Substitute back

2x = 1/2 → x = −1
2x = 2 → x = 1
Answer: x = −1 or x = 1

2.4 Valid Argument Forms

Modus Ponens (Affirming the Antecedent) — VALID ✓

Premise 1: p → q
Premise 2: p
Conclusion: ∴ q

Modus Tollens (Denying the Consequent) — VALID ✓

Premise 1: p → q
Premise 2: ¬q
Conclusion: ∴ ¬p

Hypothetical Syllogism — VALID ✓

Premise 1: p → q
Premise 2: q → r
Conclusion: ∴ p → r

2.5 Invalid Argument Forms (Fallacies)

Affirming the Consequent (INVALID ✗): p → q, q, ∴ p
Denying the Antecedent (INVALID ✗): p → q, ¬p, ∴ ¬q

3 Trigonometry & Surds

3.1 Surds — Rationalization

Worked Example 6

Simplify: (2√3 + 3√2)/√6

Solution

Step 1: Multiply numerator and denominator by √6

= [(2√3 + 3√2) × √6] / (√6 × √6)

Step 2: Expand numerator

= (2√18 + 3√12) / 6

Step 3: Simplify surds: √18 = 3√2, √12 = 2√3

= (2(3√2) + 3(2√3)) / 6
= (6√2 + 6√3) / 6
= √2 + √3
Answer: √2 + √3
Worked Example 7

Rationalize: 4/(3√5 − 2√3)

Solution

Step 1: Multiply by conjugate (3√5 + 2√3)

= [4(3√5 + 2√3)] / [(3√5 − 2√3)(3√5 + 2√3)]

Step 2: Denominator (difference of squares)

(3√5)² − (2√3)² = 45 − 12 = 33

Step 3: Expand numerator

= (12√5 + 8√3) / 33
Answer: (12√5 + 8√3)/33

Worked Example 8

Without tables, evaluate cos 15°

Solution

Step 1: Write 15° = 45° − 30°

Step 2: Apply cos(A−B) formula

cos(45° − 30°) = cos45°cos30° + sin45°sin30°
= (1/√2)(√3/2) + (1/√2)(1/2)

Step 3: Rationalize

Find cos15° sin15°

Solution

cos15° sin15° = (1/2) sin(2×15°)
= (1/2) sin30°
= (1/2)(1/2) = 1/4

3.5 Solving Trigonometric Equations

Worked Example 10

Solve: 3sin²θ − 2cosθ − 3 = 0 for 0° ≤ θ ≤ 360°

Solution

Step 1: Use identity sin²θ = 1 − cos²θ

3(1 − cos²θ) − 2cosθ − 3 = 0
3 − 3cos²θ − 2cosθ − 3 = 0
−3cos²θ − 2cosθ = 0
3cos²θ + 2cosθ = 0
cosθ(3cosθ + 2) = 0

Step 2: Solve each factor

cosθ = 0  or  3cosθ + 2 = 0
θ = 90°, 270°  or  cosθ = −2/3

Step 3: For cosθ = −2/3

θ = cos⁻¹(−2/3) = 131.81° (Q2)
θ = 360° − 131.81° = 228.19° (Q3)
Answer: θ = 90°, 131.81°, 228.19°, 270°

4 Matrices & Determinants

4.1 Matrix Operations

  • Addition/Subtraction: Add/subtract corresponding elements (matrices must be same size)
  • Scalar Multiplication: Multiply every element by the scalar
  • Matrix Multiplication: For A(m×n) and B(n×p), product AB is (m×p). Rule: Row × Column
Worked Example 11

Given A = [[3,−2],[4,1]] and B = [[2,3],[−1,5]], find 2A − 3B

Solution

Step 1: 2A = [[6,−4],[8,2]]

Step 2: 3B = [[6,9],[−3,15]]

Step 3: Subtract

2A − 3B = [[6−6, −4−9],[8−(−3), 2−15]]
= [[0, −13],[11, −13]]
Answer: [[0, −13],[11, −13]]

4.2 Determinants

2×2: For A = [[a,b],[c,d]], |A| = ad − bc

3×3: For A = [[a,b,c],[d,e,f],[g,h,i]]:
|A| = a(ei − fh) − b(di − fg) + c(dh − eg)
Worked Example 12

Evaluate: |[[2,1,3],[1,0,2],[3,2,1]]|

Solution

Step 1: Expand along first row

= 2|[[0,2],[2,1]]| − 1|[[1,2],[3,1]]| + 3|[[1,0],[3,2]]|

Step 2: Calculate 2×2 determinants

= 2(0×1 − 2×2) − 1(1×1 − 2×3) + 3(1×2 − 0×3)
= 2(0 − 4) − 1(1 − 6) + 3(2 − 0)
= 2(−4) − 1(−5) + 3(2)
= −8 + 5 + 6
= 3
Answer: 3

4.3 Inverse of a Matrix

2×2 Inverse: For A = [[a,b],[c,d]]:
A⁻¹ = (1/|A|) × [[d,−b],[−c,a]]
where |A| = ad − bc ≠ 0
Properties:
(AB)⁻¹ = B⁻¹A⁻¹  |  (A⁻¹)⁻¹ = A  |  AA⁻¹ = A⁻¹A = I
Worked Example 13

Find the inverse of A = [[5,3],[3,2]]

Solution

Step 1: Calculate determinant

|A| = 5×2 − 3×3 = 10 − 9 = 1

Step 2: Apply formula

A⁻¹ = (1/1) × [[2,−3],[−3,5]] = [[2,−3],[−3,5]]
Answer: [[2,−3],[−3,5]]
Worked Example 14

Verify (AB)⁻¹ = B⁻¹A⁻¹ for:

A = [[3,1],[4,2]], B = [[2,−1],[−4,3]]

Solution

Step 1: Calculate AB

AB = [[3(2)+1(−4), 3(−1)+1(3)],[4(2)+2(−4), 4(−1)+2(3)]]
= [[6−4, −3+3],[8−8, −4+6]]
= [[2, 0],[0, 2]]

Step 2: Find (AB)⁻¹

|AB| = 2×2 − 0×0 = 4
(AB)⁻¹ = (1/4)[[2, 0],[0, 2]] = [[1/2, 0],[0, 1/2]]

Step 3: Find B⁻¹

|B| = 2(3) − (−1)(−4) = 6 − 4 = 2
B⁻¹ = (1/2)[[3, 1],[4, 2]] = [[3/2, 1/2],[2, 1]]

Step 4: Find A⁻¹

|A| = 3(2) − 1(4) = 6 − 4 = 2
A⁻¹ = (1/2)[[2, −1],[−4, 3]] = [[1, −1/2],[−2, 3/2]]

Step 5: Calculate B⁻¹A⁻¹

B⁻¹A⁻¹ = [[3/2, 1/2],[2, 1]] × [[1, −1/2],[−2, 3/2]]
= [[3/2−1, −3/4+3/4],[2−2, −1+3/2]]
= [[1/2, 0],[0, 1/2]]

Therefore: (AB)⁻¹ = B⁻¹A⁻¹ ✓

4.4 Solving Systems with Matrices

Worked Example 15

Solve: 2x − y + 3z = 9, x + 2y − z = 3, 3x + y − 2z = 4

Solution (Cramer's Rule)

Step 1: Find |A|

|A| = 2|[[2,−1],[1,−2]]| + 1|[[1,−1],[3,−2]]| + 3|[[1,2],[3,1]]|
= 2(−4+1) + 1(−2+3) + 3(1−6)
= 2(−3) + 1(1) + 3(−5)
= −6 + 1 − 15 = −20

Step 2: Find |Ax|

|Ax| = 9(−4+1) + 1(−6+4) + 3(3−8) = −27 − 2 − 15 = −44
x = −44/−20 = 2.2

Step 3: Find |Ay|

|Ay| = 2(−6+4) − 9(−2+3) + 3(4−9) = −4 − 9 − 15 = −28
y = −28/−20 = 1.4

Step 4: Find |Az|

|Az| = 2(8−3) + 1(4−9) + 9(1−6) = 10 − 5 − 45 = −40
z = −40/−20 = 2
Answer: x = 2.2, y = 1.4, z = 2

5 Quadratic Functions & Graphs

5.1 Quadratic Function Forms

FormEquationFeatures
Standardy = ax² + bx + cy-intercept = c
Vertexy = a(x−h)² + kVertex = (h,k)
Factoredy = a(x−p)(x−q)Roots at x = p, q

5.2 Discriminant Analysis

Discriminant: Δ = b² − 4ac
Δ ValueNature of Roots
Δ > 0Real, distinct
Δ = 0Real, equal
Δ < 0Complex (not real)
Worked Example 16

Find range of k for which f(x) = 2x² − 3x + (k+1) is always positive

Solution

Step 1: For always positive, need a > 0 ✓ (a = 2) and Δ < 0

Step 2: Calculate discriminant

Δ = (−3)² − 4(2)(k+1)
= 9 − 8k − 8
= 1 − 8k

Step 3: Set Δ < 0

1 − 8k < 0
1 < 8k
k > 1/8
Answer: k > 1/8
Worked Example 17

f(x) = ax² + bx + c has minimum value −4 at x = 2. If f(0) = 8, find a, b, c

Solution

Step 1: Vertex form: f(x) = a(x−2)² − 4

Step 2: Use f(0) = 8

a(0−2)² − 4 = 8
4a − 4 = 8
4a = 12
a = 3

Step 3: Expand

f(x) = 3(x−2)² − 4
= 3(x² − 4x + 4) − 4
= 3x² − 12x + 12 − 4
= 3x² − 12x + 8
Answer: a = 3, b = −12, c = 8

5.3 Tangency Conditions

Line y = mx + c is tangent to y = ax² + bx + c when:
Substitute line into curve → resulting quadratic has Δ = 0
Worked Example 18

Find k such that y = 2x + k is tangent to y = x² + 3x − 1

Solution

Step 1: Set equal

x² + 3x − 1 = 2x + k
x² + x − 1 − k = 0

Step 2: For tangency, Δ = 0

1² − 4(1)(−1−k) = 0
1 + 4 + 4k = 0
5 + 4k = 0
k = −5/4
Answer: k = −5/4

5.4 Maximum and Minimum Values

ConditionExtremumValue
a > 0Minimumk = c − b²/(4a)
a < 0Maximumk = c − b²/(4a)
Worked Example 19

Find maximum value of f(x) = 6 + 5x − x²

Solution

Step 1: Identify a = −1, b = 5, c = 6

Step 2: Since a < 0, maximum exists

Step 3: Find x at maximum

x = −b/(2a) = −5/(2×−1) = 5/2 = 2.5

Step 4: Calculate maximum value

f(2.5) = 6 + 5(2.5) − (2.5)²
= 6 + 12.5 − 6.25
= 12.25
Answer: Maximum value = 12.25

5.5 Roots and Coefficients

For ax² + bx + c = 0 with roots α and β:
Sum of roots: α + β = −b/a
Product of roots: αβ = c/a

Forming Equations from Roots:
x² − (α+β)x + αβ = 0
Worked Example 20

Roots are 2+√3 and 2−√3. Find the equation.

Solution

Step 1: Sum of roots

(2+√3) + (2−√3) = 4

Step 2: Product of roots

(2+√3)(2−√3) = 4 − 3 = 1

Step 3: Form equation

x² − 4x + 1 = 0
Answer: x² − 4x + 1 = 0

How many lead balls r=3cm from sphere r=15cm?

6.5 Composite Solids

Worked Example 27

Hemisphere r=14cm on cylinder r=14cm, h=20cm. Find TSA.

Solution

Step 1: Curved surface of hemisphere

= 2πr² = 2π(14)² = 392π cm²

Step 2: Curved surface of cylinder

= 2πrh = 2π(14)(20) = 560π cm²

Step 3: Base of cylinder

= 1148 × 22/7 = 3608 cm²

7.2 Distance Along Meridian

Points on same meridian with latitudes θ₁ and θ₂:
Distance = (θ/360) × 2πR
Where θ = |θ₁ − θ₂| (angular difference)
Worked Example 28

Latitudes 30°N and 20°S, R=6400km. Find distance.

Solution

Step 1: Angular difference

θ = 30° + 20° = 50°

Step 2: Distance

d = (50/360) × 2 × (22/7) × 6400
= (50/360) × 40228.57
= 5587.3 km
Answer: ≈ 5585 km

7.3 Distance Along Parallel

Points on same latitude θ with longitude difference Δλ:
Radius of parallel = R cos θ
Distance = (Δλ/360) × 2πR cos θ
Worked Example 29

P(50°N,20°W), Q(50°N,40°E), R=6400km. Find PQ.

Solution

Step 1: Longitude difference

Δλ = 20° + 40° = 60°

Step 2: Radius of parallel

r = 6400 cos 50° = 6400 × 0.6428 = 4113.9 km

Step 3: Distance

d = (60/360) × 2 × (22/7) × 4113.9
= (1/6) × 25858.2
= 4310 km

7.4 Nautical Miles

1 nautical mile = 1 minute of arc along a great circle

Distance (nm) = Angular distance in minutes
1° = 60 nautical miles
Worked Example 30

A(40°N,30°W) to B(40°N,50°E). Find distance in nm.

Solution

Step 1: Longitude difference = 80°

Step 2: Along parallel at 40°N

Angular distance = 80° × cos 40°
= 80 × 0.766 = 61.28°
= 61.28 × 60 = 3676.8 nm

7.5 Local Time and Longitude

Key Rule:
15° longitude = 1 hour time difference
1° longitude = 4 minutes time difference
East is ahead of West
Worked Example 31

Local time at A(45°E) = 4:00 pm. Find time at B(60°W).

Solution

Step 1: Longitude difference

Δλ = 45° + 60° = 105°

Step 2: Time difference

Δt = (105/15) hours = 7 hours

Step 3: B is West of A, so B is behind

Time at B = 4:00 pm − 7 hours = 9:00 am
Answer: 9:00 am
Worked Example 32

Takeoff at 30°N,45°E at 8:00am. Fly to 30°N,75°E. Flight = 6 hours. Find arrival local time.

Solution

Step 1: Longitude difference = 30°

Step 2: Time difference = 30/15 = 2 hours (destination is East, so ahead)

Step 3: Arrival in departure time zone

8:00 am + 6 hours = 2:00 pm

Step 4: Convert to destination local time

2:00 pm + 2 hours = 4:00 pm
Answer: 4:00 pm

8 Binary Operations

8.1 Definition

A binary operation * on set S assigns to each pair (a,b) ∈ S×S a unique element a*b ∈ S.

8.2 Properties

PropertyDefinition
Closurea*b ∈ S for all a,b ∈ S
Commutativea*b = b*a
Associative(a*b)*c = a*(b*c)
Identitya*e = e*a = a
Inversea*b = b*a = e
Worked Example 35

a*b = a+b−3ab. Find identity element.

Solution

Step 1: Let e be identity

a*e = a
a+e−3ae = a
e−3ae = 0
e(1−3a) = 0

Step 2: Since this must hold for all a: e = 0

Answer: Identity = 0
Worked Example 36

Same operation, find inverse of 1/2

Solution

1/2 − (1/2)b = 0
(1/2)(1−b) = 0
b = 1
Answer: Inverse of 1/2 is 1

Worked Example 38

aΔb = (a²−b²)/(a−b). Simplify.

Solution
aΔb = (a−b)(a+b)/(a−b) = a+b
Answer: aΔb = a+b
Worked Example 39

a⋆b = 2a−b+ab. Solve 2⋆x = 3

Solution
2⋆x = 2(2) − x + 2x = 4 + x
4 + x = 3
x = −1
Answer: x = −1

8.3 Closure Test

Worked Example 40

Is a*b = (a+b)/2 closed on integers?

Solution

Take a = 1, b = 2 (both integers)

1*2 = (1+2)/2 = 3/2 = 1.5

1.5 is NOT an integer

Answer: NOT closed on integers

9 Financial Mathematics

9.1 Simple Interest

I = PRT/100
A = P + I = P(1 + RT/100)

Where: P = Principal, R = Rate (% per annum), T = Time (years), A = Amount

9.2 Compound Interest

A = P(1 + R/100)ⁿ
Where n = number of years

9.3 Depreciation

A = P(1 − R/100)ⁿ

Step 2: Acceleration = dv/dt

10.2 Particle at Rest

Particle at rest when v = 0

When is particle at rest?

Solution
6t² − 30t + 24 = 0
t² − 5t + 4 = 0
(t−1)(t−4) = 0
t = 1 or t = 4
Answer: t = 1s or t = 4s

10.3 Distance Travelled

Worked Example 45

Distance in first 3 seconds

Solution
s(3) = 2(27) − 15(9) + 24(3)
= 54 − 135 + 72
= −9 m

Since displacement can be negative, distance = |−9| = 9 m (if no direction change)

But check if particle changes direction:

At t=1: v=0 (changes direction)
s(1) = 2 − 15 + 24 = 11
Distance from t=0 to 1: |11 − 0| = 11 m
Distance from t=1 to 3: |−9 − 11| = 20 m
Total = 31 m
Answer: 31 m

10.4 Sequences and Series

Worked Example 46

Sn = 2n² + 3n. Find first term and nth term.

Solution

Step 1: First term = S₁

S₁ = 2(1)² + 3(1) = 5

Step 2: nth term = Sn − S(n−1)

Tn = [2n² + 3n] − [2(n−1)² + 3(n−1)]
= 2n² + 3n − [2(n²−2n+1) + 3n−3]
= 2n² + 3n − [2n² − 4n + 2 + 3n − 3]
= 2n² + 3n − [2n² − n − 1]
= 2n² + 3n − 2n² + n + 1
= 4n + 1
Answer: First term = 5, nth term = 4n + 1
